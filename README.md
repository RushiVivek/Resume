 # Resume

This directory contains the source files and generated documents for my resume, built with [Awesome-CV](https://github.com/posquit0/Awesome-CV).

## Contents

- Resume source files
- Supporting assets and configuration
- Generated resume output

## Usage

1. Install a LaTeX distribution with the packages required by Awesome-CV.
2. Open the main `.tex` file in this directory.
3. Compile it with your preferred LaTeX editor or command-line tool.

For the best results, use a current TeX Live or MiKTeX installation and compile with XeLaTeX or LuaLaTeX as recommended by Awesome-CV.
